# LEAD Documentation

Architecture documentation, domain model class diagram, sequence diagrams, and use-case specifications for the `lead-node` crate.

## Contents

- **`domain-model.mmd` / `domain-model.png`**: Complete class diagram showing all LEAD subsystems, interfaces, and relationships.
- **`use-cases/`**: 10 detailed use-case documents specifying the runtime behaviors of the LEAD node.
- **`sequence-diagrams/`**: 8 sequence diagrams illustrating message flows between LEAD components, peer nodes, and external clients.
- **`render-mermaid.sh`**: Helper script to render Mermaid `.mmd` diagrams to dark-mode `.png` images using `mmdc`.
- **`puppeteer-config.json`**: Headless Chromium configuration for Mermaid diagram rendering.
