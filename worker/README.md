# Worker Service

The `worker` service is a high-performance Python gRPC microservice that performs aerodynamic analysis and fitness evaluation for 3D-printable aircraft designs generated by the genetic algorithm.

## File & Code Structure

### 1. `service.py`
Implements the gRPC service layer and coordinates asynchronous evaluations across thread pools.

- **`EvaluatorServicer(eval_pb2_grpc.EvaluatorServicer)`**:
  - `__init__(fitness_evaluator, worker_id, gene_count, logger, semaphore_size=1)`: Initializes servicer with fitness evaluation engine, worker identifier, gene length (10), and concurrency semaphore.
  - `async Evaluate(request, context) -> EvaluationResult`: Single-individual evaluation RPC endpoint.
  - `async EvaluateBatch(request, context) -> BatchResponse`: Batch evaluation RPC endpoint. Unpacks individuals, validates gene counts, evaluates candidate designs concurrently/serially via thread pool executor, and formats results.
  - `_rejection() -> EvaluationResult`: Returns fallback `REJECT_FITNESS` (`-1e9`).
  - `_valid_genes(genes: list[float]) -> bool`: Verifies gene vector matches expected length (10).
  - `async _evaluate(genes: list[float]) -> EvaluationOutcome`: Runs CPU-bound aerodynamic evaluation in `loop.run_in_executor`.

---

### 2. `fitness.py`
Calculates the scalar optimization score, aerodynamic penalties, and volume constraints.

- **Constants**:
  - `REJECT_FITNESS = -1e9`: Value assigned to structurally infeasible or untrimmable designs.
- **`EvaluationOutcome`** (dataclass):
  - `fitness: float`: Computed fitness score.
  - `fuselage_volume_mm3: float`: Enclosed fuselage volume in $\text{mm}^3$.
  - `aero: AeroResult | None`: Aerodynamic trim outcome (or `None` if rejected).
  - `rejected: bool`: Boolean indicating if evaluation was rejected.
- **`FitnessEvaluator`**:
  - `__init__(aero_evaluator, config, baseline, bounds, logger)`: Configures baseline design, gene bounds, and weights.
  - `evaluate_genes(genes: Sequence[float]) -> EvaluationOutcome`: Decodes normalized $[0, 1]$ genes to dimensional parameters and evaluates.
  - `evaluate_params(params: dict[str, float]) -> EvaluationOutcome`:
    - Checks fuselage volume: $V_{\text{fuse}} \ge V_{\text{min}}$.
    - Computes aerodynamic trim via `AeroEvaluator`.
    - Applies angle-of-attack and static pitch stability penalties:
      $$\text{fitness} = (L/D) - w_\alpha |\alpha_{\text{trim}}| - w_{\text{stab}} \max(0, C_{m_\alpha})^2$$

---

### 3. `aero.py`
Aerodynamic solver integration using AeroSandbox (Vortex Lattice Method / VLM).

- **`AeroResult`** (dataclass):
  - `ld: float`: Lift-to-drag ratio ($L/D$) at trimmed flight.
  - `alpha_trim: float`: Trimmed angle of attack in degrees.
  - `cm_alpha: float`: Pitch stability derivative $\partial C_m / \partial \alpha$.
- **`AeroEvaluator`** (Protocol):
  - `evaluate(params: dict[str, float]) -> AeroResult | None`
- **`solve_trim(cl_req, alpha_sweep, cl_list, cd_list, cm_list) -> AeroResult | None`**:
  - Interpolates cruise angle of attack $\alpha_{\text{trim}}$ such that $C_L(\alpha) = C_{L,\text{req}}$.
  - Interpolates $C_{D,\text{trim}}$ to obtain $L/D = C_{L,\text{req}} / C_{D,\text{trim}}$.
  - Computes numerical derivative $C_{m_\alpha} = \frac{d C_m}{d \alpha}$.
- **`AerosandboxAeroEvaluator`**:
  - `evaluate(params) -> AeroResult | None`: Orchestrates mass estimation, wing reference area, required $C_L$, geometry mesh generation, and $\alpha$-sweep solver.
  - `_reference_area(params) -> float`: Computes wing trapezoidal planform area: $S_{\text{ref}} = 2 \cdot b \cdot \frac{c_{\text{root}} + c_{\text{tip}}}{2} \cdot 10^{-6}$.
  - `_required_cl(weight_n, s_ref) -> float`: Computes cruise $C_{L,\text{req}} = \frac{2 W}{\rho_\infty V_\infty^2 S_{\text{ref}}}$.
  - `_build_airplane(params) -> asb.Airplane`: Generates 3D AeroSandbox parametric airplane model with Main Wing, Horizontal Stabilizer, and Vertical Stabilizer.
  - `_airfoils(params) -> tuple[asb.Airfoil, asb.Airfoil]`: Builds parametric 4-digit NACA airfoil (`nacaMPTT`) for main wing and symmetrical `naca0010` for tail surfaces.
  - `_run_sweep(airplane) -> tuple[np.ndarray, list[float], list[float], list[float]]`: Runs 13-point Vortex Lattice Method sweep for $\alpha \in [-2^\circ, 10^\circ]$.

---

### 4. `geometry.py`
Parametric geometric modeling and 10-gene decoding.

- **`decode_genes(genes, baseline, bounds) -> dict[str, float]`**:
  - Maps 10 normalized gene values in $[0, 1]$ to dimensional physical parameters:
    1. `wing_span`: Wing semi-span ($b/2$) in mm.
    2. `wing_root_chord`: Root chord $c_{\text{root}}$ in mm.
    3. `wing_tip_chord`: Tip chord $c_{\text{tip}}$ in mm.
    4. `wing_sweep`: Leading-edge sweep angle $\Lambda$ in deg.
    5. `wing_dihedral`: Wing dihedral angle $\Gamma$ in deg.
    6. `wing_twist`: Geometric tip twist $\theta_{\text{twist}}$ in deg.
    7. `naca_m`: NACA maximum camber (0-9%).
    8. `naca_p`: NACA camber location (0-9 tenths).
    9. `naca_t`: NACA maximum thickness (1-30%).
    10. `tail_x_pos`: Longitudinal tail moment arm in mm.
- **`fuselage_volume_mm3(params) -> float`**: Computes enclosed volume of the 3D-printable payload fuselage.
- **`calculate_total_mass_and_weight(params, rho_material, g) -> tuple[float, float]`**: Computes aircraft empty weight, payload mass, and total gravitational weight.

---

### 5. `hilbert.py`
Multi-probe Compact Hilbert curve embedding (Python reference implementation).

- **`HilbertEncoder`**:
  - `__init__(ndims, bits)`: Configures dimensionality (10) and bit precision (16 bits/dimension = 160-bit scalar).
  - `encode_hex(point, curve, hex_width) -> str`: Maps 10D continuous normalized vector to hex scalar index for probe curve $c$.
- **`hilbert_encode_hex(point, bits, ndims, hex_width) -> str`**:
  - Skilling (2004) algorithm implementation interleaving multi-dimensional bits directly into hex string format.
- **`py_round(x: float) -> int`**:
  - Deterministic round-half-to-even matching standard IEEE / Skilling rounding.

---

### 6. `config.py`
Environment configuration dataclass and defaults.

- **`WorkerConfig`** (dataclass):
  - `worker_id: str`: Unique worker process ID.
  - `v_min_fuse_mm3: float`: Minimum allowable fuselage payload volume ($150{,}000\text{ mm}^3$).
  - `worker_concurrency: int`: Max concurrent evaluation tasks.
  - `v_cruise: float`: Design cruise velocity ($20.0\text{ m/s}$).
  - `rho_air: float`: Air density ($1.225\text{ kg/m}^3$).
  - `rho_material: float`: 3D printing filament density.
  - `w_alpha: float`: Pitch trim angle penalty weight ($0.1$).
  - `w_stability: float`: Dynamic pitch instability penalty weight ($100.0$).
- **`GeneBound`** (dataclass): Defines `[min_val, max_val]` for each parameter.
- **`load_config() -> WorkerConfig`**: Reads runtime environment variables.

---

### 7. `main.py`
- **`main()`**: Initializes structured JSON logging, instantiates `AerosandboxAeroEvaluator` and `FitnessEvaluator`, binds `grpc.aio.server()`, registers `EvaluatorServicer`, and handles graceful shutdown.
