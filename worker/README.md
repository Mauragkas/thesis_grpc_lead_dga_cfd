# Worker Service

The `worker` service is a high-performance Python gRPC microservice that performs aerodynamic analysis, tail volume sizing, dynamic powertrain modeling, mission simulation, and fitness evaluation for 3D-printable fixed-wing aircraft designs generated by the genetic algorithm.

## File & Code Structure

### 1. `service.py`
Implements the gRPC service layer and coordinates asynchronous evaluations across thread pools.

- **`EvaluatorServicer(eval_pb2_grpc.EvaluatorServicer)`**:
  - `__init__(fitness_evaluator, worker_id, gene_count, logger, semaphore_size=1)`: Initializes servicer with fitness evaluation engine, worker identifier, gene length (10), and concurrency semaphore.
  - `async Evaluate(request, context) -> EvaluationResult`: Single-individual evaluation RPC endpoint.
  - `async EvaluateBatch(request, context) -> BatchResponse`: Batch evaluation RPC endpoint. Unpacks candidate individuals, validates gene counts, executes CPU-bound evaluations in `loop.run_in_executor`, and returns fitness scores.
  - `_rejection() -> EvaluationResult`: Returns fallback `REJECT_FITNESS` (`-1e9`).
  - `_valid_genes(genes: list[float]) -> bool`: Verifies gene vector matches expected length (10).
  - `async _evaluate(genes: list[float]) -> EvaluationOutcome`: Runs aerodynamic evaluation in thread executor.

---

### 2. `fitness.py`
Calculates the scalar optimization score, aerodynamic penalties, powertrain limits, and mission constraints.

- **Constants**:
  - `REJECT_FITNESS = -1e9`: Assigned to infeasible, untrimmable, or volume/mission-violating designs.
- **`EvaluationOutcome`** (dataclass):
  - `fitness: float`: Computed aggregate fitness score.
  - `fuselage_volume_mm3: float`: Enclosed fuselage payload volume in $\text{mm}^3$.
  - `aero: AeroResult | None`: Aerodynamic trim outcome (or `None` if rejected).
  - `rejected: bool`: Boolean indicating whether design was rejected.
  - `mission: MissionOutcome | None`: Simulated dynamic mission outcome (takeoff distance, energy consumed).
- **`FitnessEvaluator`**:
  - `__init__(aero_evaluator, config, baseline, bounds, logger, mission_simulator)`: Configures baseline design, gene bounds, mission simulator, and tail sizing targets.
  - `evaluate_genes(genes: Sequence[float]) -> EvaluationOutcome`: Decodes normalized $[0, 1]$ genes to dimensional parameters and evaluates.
  - `evaluate_params(params: dict[str, float]) -> EvaluationOutcome`:
    1. Checks fuselage volume: $V_{\text{fuse}} \ge V_{\min}$ (default $20{,}000\text{ mm}^3$).
    2. Solves aerodynamic trim via `AeroEvaluator` (VLM sweep).
    3. Calculates aerodynamic base fitness:
       $$\text{fitness}_{\text{base}} = (L/D) - w_\alpha |\alpha_{\text{trim}}| - w_{\text{stab}} \max(0, C_{m_\alpha})^2 - w_{\text{moment}} (C_{m,\text{trim}})^2$$
    4. Runs dynamic mission simulation (`MissionSimulator`):
       - Simulates ground roll takeoff distance $s_{\text{to}}$ and cruise energy consumption $E_{\text{wh}}$.
       - If takeoff distance exceeds $s_{\text{max}}$, or climb/cruise fails, the design is rejected.
       - Applies takeoff distance and energy consumption penalties:
         $$\text{fitness} = \text{fitness}_{\text{base}} - w_{\text{to}} \left(\frac{s_{\text{to}}}{s_{\max}}\right)^2 - w_{\text{energy}} \left(\frac{E_{\text{wh}}}{5.0}\right)$$

---

### 3. `aero.py`
Aerodynamic solver integration using AeroSandbox (Vortex Lattice Method / VLM).

- **`AeroResult`** (dataclass):
  - `ld: float`: Trimmed lift-to-drag ratio ($L/D$).
  - `alpha_trim: float`: Trimmed angle of attack in degrees.
  - `cm_alpha: float`: Pitch stability derivative $\partial C_m / \partial \alpha$.
  - `cm_trim: float`: Pitching moment coefficient at trim $C_{m,\text{trim}}$.
  - `mass_kg: float`: Total aircraft estimated mass.
  - `s_ref: float`: Wing reference planform area in $\text{m}^2$.
  - `polar: AerodynamicPolar | None`: Fitted drag polar curve for mission simulation.
- **`AerosandboxAeroEvaluator`**:
  - `evaluate(params) -> AeroResult | None`: Orchestrates mass estimation, wing reference area, required $C_L$, 3D geometry mesh generation, and $\alpha$-sweep solver.
  - `_build_airplane(params) -> asb.Airplane`: Generates 3D AeroSandbox parametric airplane model with Main Wing, Horizontal Stabilizer, and Vertical Stabilizer.
  - `_run_sweep(airplane) -> tuple[...]`: Runs 13-point Vortex Lattice Method sweep for $\alpha \in [-2^\circ, 10^\circ]$.

---

### 4. `geometry.py`
Parametric geometric modeling and 10-gene decoding with clean domain models.

- **Domain Models**:
  - **`Fuselage`**: Parametric body (`length`, `nose_ratio`, `tail_ratio`, `max_diameter`) computing enclosed payload volume and section lengths.
  - **`WingGeometry`**: Trapezoidal planform (`span`, `root_chord`, `tip_chord`, `wingspan`, `planform_area`, `mac` Mean Aerodynamic Chord).
  - **`TailVolumeTargets`**: Target horizontal ($V_h$) and vertical ($V_v$) tail volume coefficients for automatic surface area sizing.
- **`decode_genes(genes, baseline, bounds, tail_targets) -> dict[str, float]`**:
  - Maps 10 normalized gene values in $[0, 1]$ to dimensional physical parameters:
    1. `wing_span`: Wing semi-span ($b/2 \in [80.0, 220.0]\text{ mm}$).
    2. `wing_root_chord`: Root chord ($c_{\text{root}} \in [35.0, 75.0]\text{ mm}$).
    3. `wing_tip_chord`: Tip chord ($c_{\text{tip}} \in [10.0, 45.0]\text{ mm}$).
    4. `wing_sweep`: Leading-edge sweep angle ($\Lambda \in [0.0, 25.0]^\circ$).
    5. `wing_dihedral`: Wing dihedral angle ($\Gamma \in [0.0, 4.0]^\circ$).
    6. `wing_twist`: Geometric tip twist ($\theta_{\text{twist}} \in [-4.0, 0.0]^\circ$).
    7. `wing_x_pos`: Wing longitudinal position on fuselage ($x \in [55.0, 95.0]\text{ mm}$).
    8. `naca_m`: NACA airfoil maximum camber ($m \in [0.0, 5.0]\%$).
    9. `fuse_length`: Fuselage body length ($L \in [200.0, 350.0]\text{ mm}$).
    10. `fuse_max_diam`: Fuselage maximum diameter ($D_{\max} \in [14.0, 32.0]\text{ mm}$).
- **`calculate_tail_planform_areas(wing, arm_h, arm_v, targets)`**:
  - Sizes horizontal and vertical tail areas using the Stan Hall / Pazmany volume coefficient method:
    $$S_h = \frac{V_h \cdot S_{\text{wing}} \cdot \text{MAC}}{l_h}, \quad S_v = \frac{V_v \cdot S_{\text{wing}} \cdot b}{l_v}$$

---

### 5. `powertrain/` (Electric Propulsion Subsystem)
Modular electro-mechanical powertrain simulation:

- **`battery.py`**: LiPo battery model (`Battery`, `Capacity`, `CellCount`) computing open-circuit voltage, internal resistance voltage drop under load, and state of charge.
- **`motor.py`**: Brushless DC motor model (`Motor`, `MotorKV`, `MotorResistance`) calculating back-EMF, shaft torque, current draw, and ohmic losses.
- **`propeller.py`**: Propeller model (`Propeller`, `PropellerDimension`) computing non-dimensional advance ratio $J = V / (n D)$, thrust coefficient $C_T(J)$, power coefficient $C_P(J)$, net thrust, and mechanical power.
- **`powertrain.py`**: `Powertrain` model solving the coupled motor-propeller operating point (RPM, current, thrust, electrical power, and combined efficiency).

---

### 6. `mission/` (Dynamic Trajectory & Flight Simulation)
- **`polar.py`**: `AerodynamicPolar` encapsulates parabolic drag polar approximations ($C_D = C_{D0} + K \cdot C_L^2$) fitted from VLM sweep results.
- **`trajectory.py`**: `MissionSimulator` and `MissionConfig` simulating full mission phases:
  1. **Takeoff Ground Roll**: Numerical integration of aircraft acceleration $a = (T - D - \mu (W - L)) / m$ from standstill to rotation speed $V_{\text{rot}} = 1.15 \cdot V_{\text{stall}}$.
  2. **Climb & Cruise**: Calculates thrust required, battery energy consumed ($E_{\text{wh}}$), and verify flight endurance against target duration.
  - Returns `MissionOutcome` with `completed`, `takeoff_distance_m`, `energy_consumed_wh`, and `failure_reason`.

---

### 7. `slender_aerodynamics.py`
Slender body theory for aerodynamic drag corrections:
- `get_fuselage_wetted_area(params) -> float`: Calculates true surface area of the parameterized revolution fuselage.
- Estimates turbulent boundary layer skin-friction coefficient $C_f$ and parasite drag contributions.

---

### 8. `hilbert.py`
Multi-probe Compact Hilbert curve embedding delegating to the unified Rust crate `hilbert_rs` via PyO3 bindings:
- `HilbertEncoder`: 10-dimensional space-filling curve with 16-bit precision per dimension (160-bit key space) matching the orchestrator's encoding exactly.

---

### 9. `config.py`
Runtime configuration dataclass and environment variable loader:

| Variable | Default | Description |
|---|---|---|
| `WORKER_ID` | `HOSTNAME` | Unique worker process identifier |
| `V_MIN_FUSE_MM3` | `20000.0` | Minimum payload fuselage volume in $\text{mm}^3$ |
| `WORKER_CONCURRENCY` | `1` | Max concurrent worker evaluation tasks |
| `ENABLE_MISSION_SIM` | `true` | Enables dynamic mission simulation and powertrain check |
| `MAX_TAKEOFF_DISTANCE_M` | `30.0` | Maximum allowable ground roll takeoff distance |
| `TARGET_FLIGHT_TIME_S` | `30.0` | Target cruise duration for energy calculation |
| `ENABLE_TAIL_SIZING` | `false` | Enables automatic Stan Hall tail volume sizing |
| `TARGET_VH` | `0.50` | Target horizontal tail volume coefficient |
| `TARGET_VV` | `0.04` | Target vertical tail volume coefficient |
| `LOG_DIR` / `LOG_FILE_PATH` | `None` | Path / directory for structured JSON file logging |

---

### 10. `main.py`
Initializes dual logging (stdout + JSON file layer), instantiates `AerosandboxAeroEvaluator` and `FitnessEvaluator`, binds `grpc.aio.server()`, registers `EvaluatorServicer`, and handles graceful shutdown signals.
