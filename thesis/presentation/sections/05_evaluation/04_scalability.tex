      \begin{itemize}
        \item Παράλληλο κλάσμα $p \approx 0.96$ (Amdahl / Gustafson).

      \end{itemize}

      \textbf{Envoy Least-Request vs Round-Robin:}
      \begin{itemize}
        \item Εξάλειψη head-of-line blocking.
        \item Μείωση του $P_{99}$ latency κατά $28\%$.
      \end{itemize}
