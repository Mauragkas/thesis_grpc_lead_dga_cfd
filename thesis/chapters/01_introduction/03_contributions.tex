\section{Συνεισφορά της Εργασίας}
\label{sec:intro_contributions}

Οι βασικές επιστημονικές και τεχνολογικές συνεισφορές της παρούσας εργασίας συνοψίζονται ως εξής:

\begin{enumerate}
    \item \textbf{Ιεραρχικός Αξιολογητής 3 Επιπέδων (Multi-Tier $\epsilon$-Bypass):}
    Σχεδιάζεται μία πρωτότυπη ροή αξιολόγησης τριών επιπέδων: Tier~1 (άμεση ανάκτηση γειτονικών λύσεων εντός ακτίνας $\epsilon_{\text{exact}}$), Tier~2 (ταχεία πρόβλεψη μέσω surrogate model εντός ακτίνας $R$), και Tier~3 (πλήρης αεροδυναμική προσομοίωση). Σε αντίθεση με τις κλασικές προσεγγίσεις τύπου EGO~\cite{jones1998ego,forrester2008engineering} που χρησιμοποιούν ένα ενιαίο μοντέλο Kriging, ο ιεραρχικός αυτός σχεδιασμός επιτρέπει διαφορετικές εγγυήσεις ακρίβειας σε κάθε επίπεδο, μειώνοντας σε μεγάλο βαθμό τον αριθμό κλήσεων στον πλήρη προσομοιωτή~\cite{jin2002framework}.

    \item \textbf{Κατανεμημένο Ευρετήριο Μάθησης (LEAD DHT):}
    Υλοποιείται ένας αποκεντρωμένος δακτύλιος τύπου Chord~\cite{stoica2001chord} με 60 εικονικούς κόμβους (vnodes), πολυδιάστατη κωδικοποίηση Hilbert για τη διατήρηση της χωρικής εγγύτητας στον 10-διάστατο χώρο γονιδίων, μοντέλα Learned Index (RMI)~\cite{kraska2018case} για ταχύτατη αναζήτηση εντός κόμβου, και προσαρμοστικό ρυθμιστή PID για δυναμική εξισορρόπηση φόρτου. Η συνεισφορά αυτή αποτελεί πρωτότυπο συνδυασμό ιδεών από τους τομείς των κατανεμημένων συστημάτων~\cite{wang2025lead} και της μηχανικής μάθησης σε δομές ευρετηρίου.

    \item \textbf{Αυτόνομη Μικροϋπηρεσία Surrogate σε Rust/C++:}
    Αναπτύσσεται μηχανή εκτίμησης καταλληλότητας υλοποιημένη σε Rust~\cite{matsakis2014rust}, η οποία υποστηρίζει Multi-Layer Perceptron (MLP), Gaussian Processes, Random Forests και k-NN με επιγραμμική επανακατάρτιση (online retraining) κατά τη διάρκεια της βελτιστοποίησης. Η χρήση της Rust εξασφαλίζει ασφάλεια μνήμης χωρίς garbage collector, ιδιαίτερα κρίσιμη σε κατανεμημένο περιβάλλον υψηλής απόδοσης. Η αρχιτεκτονική αυτή επεκτείνει τις κλασικές προσεγγίσεις surrogate~\cite{jin2011surrogate} με δυνατότητα συνεχούς επικαιροποίησης του μοντέλου κατά την εκτέλεση.

    \item \textbf{Αεροδυναμική Προσομοίωση σε Πραγματικό Χρόνο:}
    Ενσωματώνεται το επιταχυνόμενο μοντέλο AeroSandbox~\cite{sharpe2021aerosandbox,sharpe2022aiaa} (3D Vortex Lattice Method με ανάλυση ευστάθειας) σε κατανεμημένους Python workers. Η ενσωμάτωση αυτή παρέχει αξιόπιστους υπολογισμούς $L/D$ και $C_{m_\alpha}$ σε κλάσματα δευτερολέπτου, επιτρέποντας τη χρήση του AeroSandbox ως Tier~3 αξιολογητή σε πρακτικά χρονικά όρια και με δυνατότητα οριζόντιας κλιμάκωσης μέσω προσθήκης νέων workers.

    \item \textbf{Πλήρης Αρχιτεκτονική Παραγωγής (Production-Grade Stack):}
    Ολοκληρώνεται ένα πλήρες σύστημα παραγωγικού επιπέδου που αξιοποιεί gRPC μέσω της βιβλιοθήκης Tonic, εξισορροπητή φόρτου Envoy~\cite{klein2017envoy}, δίαυλο μηνυμάτων Apache Kafka~\cite{kreps2011kafka} για ασύγχρονη επικοινωνία μεταξύ island-κόμβων~\cite{whitley1999island,alba1999survey}, και Web Dashboard παρακολούθησης σε πραγματικό χρόνο. Πρόκειται για μία ολοκληρωμένη ορχήστρωση τεχνολογιών αιχμής που δεν έχει αναφερθεί σε συνδυασμό στην υπάρχουσα βιβλιογραφία βελτιστοποίησης UAV.
\end{enumerate}
