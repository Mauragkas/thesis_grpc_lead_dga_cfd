\section{Μικροϋπηρεσία Surrogate (MLP, GP, RF, k-NN)}
\label{sec:impl_surrogate}

Η υπηρεσία \texttt{surrogate\_node} υλοποιεί έναν πολυγλωσσικό πυρήνα σε Rust με εγγενείς (native) επεκτάσεις σε C++ για υπολογιστική επιτάχυνση σε πολυπύρηνους επεξεργαστές (OpenMP) και κάρτες γραφικών (CUDA/ROCm).

Η διαχείριση των μοντέλων διαθέτει τα εξής σχεδιαστικά γνωρίσματα:
\begin{itemize}
    \item \textbf{Κυλιόμενος Ταμιευτήρας (Sliding Window Buffer):} Διατηρεί τα πιο πρόσφατα $N_{\text{win}}$ έγκυρα δείγματα (π.χ. $1.000$ αξιολογήσεις) απορρίπτοντας παλαιά δεδομένα που δεν αντιπροσωπεύουν τον τρέχοντα εξελικτικό χώρο.
    \item \textbf{Ατομική Εναλλαγή Μοντέλου (Atomic Swapping):} Η επανεκπαίδευση εκτελείται σε ξεχωριστό νήμα στο παρασκήνιο. Μόλις ολοκληρωθεί με επιτυχία, ο ενεργός δείκτης \texttt{Arc<Model>} ενημερώνεται ατομικά χωρίς καμία διακοπή στα εισερχόμενα αιτήματα συμπερασμού.
    \item \textbf{Διαχείριση Cold Start:} Εάν ο αριθμός των διαθέσιμων δειγμάτων είναι μικρότερος του $N_{\text{min}}$, η υπηρεσία επιστρέφει κατάσταση μη-ετοιμότητας, οδηγώντας αυτόματα τα αιτήματα του Tier 2 προς το Tier 3.
\end{itemize}
